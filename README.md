# Memory Card Game

A simple memory card matching game built using HTML, CSS and JavaScript.

## About the Project

The Memory Card Game is a simple game where the player flips two cards at a time and tries to find matching pairs.

The game keeps track of the player's score and number of moves.

## Features

- Flip cards to reveal symbols
- Find matching pairs
- Score tracking
- Move tracking
- Restart game button
- Congratulations message when all pairs are found

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Click on a card to reveal its symbol.
2. Click another card.
3. If the two cards match, they remain open.
4. If they don't match, they turn back over.
5. Find all matching pairs to complete the game.
